# Creative Coding A1


General Information
This Python project intends to solve the problem of excessive class planning required by members of the fitness community. 
I am a pilates instructor and planning classes takes up much of my time and brain power. This project solves this issue by creating a class plan with the assistance of only a few prompts, allowing the class to still be tailored to the instructor. 


Technologies Used
Python & IDLE 2026


Features:
Options to created tailored class plans with options for level, prop and muscle group
Able to create plans with prompts that include any capital, lowercase or spaced words.
Many exercises embedded which are numbered when produced through the plan.

Useage
Please enter 'Pilates' when initially asked for a class style. 
Then, follow the questions by providing an answer from the options provided.
